# 交通衔接与租赁

按门到门任务核验，不把站到站时长当可达保证。每段保留运营商、起终点、当地时间、绝对时刻、行李/票务/入场条件与来源。

- 航空：分开出票、换机场/航站楼、重新托运、值机安检截止、最短衔接条件、夜间地面交通。
- 铁路：车站是否同名不同站、实名/划位、换乘与行李、跨境检查、夜车卧铺/过夜日期。
- 渡轮：车辆与旅客分别值机、港口入口、末班/天气取消、返程替代与过夜安排。
- 城市交通：购票介质、支付、末班、可达入口、推车/无障碍；地图上能搜到不等于当前路线运营。
- 时间：IANA时区与带偏移绝对时刻并存；夏令时重复/不存在时刻必须找源确认，不静默猜测。

## 租赁生命周期

详表见 [RENT01–25](../../travel-product-studio/references/coverage-and-rental.md)。本次具体订单依序核验：

选产品/供应商 → 资格与使用区域 → 实际门店和营业时段 → 订单计价/保障/押金 → 到达门店 → 验车与交接 → 使用中补能/收费/事故 → 还车准备 → 交还凭证/费用/押金后续。

- 区分车型“或同级”、行李与乘员容量；儿童座椅按实际儿童条件和供应商产品核验。
- 跨境行驶与跨国异地还车不是同一许可；电动车补能网络、支付、线缆、最低还车电量需分别核验。
- 晚取/早还要有实际门店的无人交接、钥匙、检查及责任结束规则。不要把机场全天开放等同租车柜台全天营业。
- 原始金额、税费、预付、到店付、预授权、异地费、自负额和退改分开；不推断“全险”。
- 取还端点使用`at + timeZone`，或`date + time + timeZone`。日程用`rentalRef: pickUp/dropOff`引用，不复制时刻与地点；实际构建后检查变更是否出现在交通、日程、地图和倒计时。
- 协助电话、事故流程和交还凭证以供应商的公开入口为准；普通复选框不能宣称完成现实中的验车或退款。
