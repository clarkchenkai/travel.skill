# 途中变化与替代安排

先确认人当前在哪里、当地时间、下一项不可移动事项、现有订单与可联系渠道，再提出调整。不要从旧出发地重排整趟旅程。

1. 延误/取消：确认运营商实际状态与可改选项；查下一段票、夜间交通、入住限制及行李。新建议与已改签分开。
2. 天气/闭园/罢工：查实际日期和区域，比较保留、绕行、替代与取消的费用和时间；不要用常年攻略否定实时关闭信息。
3. 成员、体能或设备变化：重查容量、步行、房间、票与分组集合；保留其他人仍有效的安排。
4. 证件/财物/设备遗失：查当地官方和供应商的适用处理入口；把原件、报警/声明、补办、银行或运营商处理分别列出，不编造电话。
5. 支付或订单提交结果不明：先读回状态，避免重复付款/取消。尚未确认的新安排不能覆盖旧订单。

每次变更输出：当前采用方案、受影响的订单/费用、仍待确认项、下一步行动。更新权威数据后回读日程、地图、交通、提醒；不要只修一个页面上的文字。涉及健康紧急情况，提供适用的当地求助入口，不替用户作诊断。
