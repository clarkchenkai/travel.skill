# 同行人与节奏

先问会改变方案的实际需求，不把“家庭”固定解释成有老人和儿童，也不把“独行”固定解释成低价或社交。

| 情境 | 会改变安排的条件 |
| --- | --- |
| 个人 | 晚到后移动、独住成本、通信与求助、自主节奏 |
| 儿童 | 实际年龄/身高、休息、餐食、床位/座椅、门票条件、监护材料 |
| 老人/体力限制 | 步行与台阶、休息、厕所、行李、转乘负担；不按年龄猜健康状况 |
| 无障碍 | 具体设备与协助需求、无台阶的真实入口、电梯运行、客房/交通确认 |
| 朋友分组 | 共同活动与可选活动、集合地点/时刻、房间、费用分摊、人数变化 |
| 商务＋休闲 | 固定会面与公司规则优先，个人延住时间和费用分开 |

把需要供应商确认的房型、床位、连通房、协助与设备条件变成待办，并保留回复证据。网页上的“适合家庭/无障碍”标签不是可达性证明。

行程密度按实际门到门时间、体能、作息调整；给天气与疲劳依赖活动留替代方案。成员分开时写明再次会合的条件，而不是让两份互斥行程都显示为全员必到。
