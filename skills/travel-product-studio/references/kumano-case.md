## 主任务应该复用的成功做法

- 共享数据、字体、导航、缓存版本与发布资源由主任务统一维护。
- 模块增量按精确SHA交付，明确父依赖、资源与未测项。
- 被否定的日封面、票纸、重装饰可撤回，事实与功能保留。
- 一次公开上线之后，后续改变到同一网址；按改变的资源做差异回读。
- 通过DOM、截图、实际动作与测试分别证明不同层面。
- 私有工作JSON没有进入Git，CI只读可分享快照；白名单负责产物边界。

## 今天暴露的问题，下一次要提前避免

| 问题 | 原因 | 下次应改 |
| --- | --- | --- |
| 反复看到旧字体/长页/菜单 | 工作树预览没同步主共享基线 | 每轮显示明确版本；看整站用当前正式URL |
| 任务完成却没上线 | 主任务回执转发多，采用到集成缺跟踪 | 采用项必须有集成与部署去向，查漏优先 |
| 每次小改都触发长串播报 | 把工具进度当用户进度 | 同逻辑成组发布，结果/阻塞才通知 |
| 大量CSS冲突 | 全模块压缩在大文件，多个尾部追加块 | 共享对象单写入人，必要时独立模块CSS，不能只删冲突标记 |
| 风格方向反复 | “高级/小巧思”未转换成可比较任务 | 局部对照、真实状态、采用后清理实验控件 |
| 首屏慢网等待明显 | 主动画共享脚本在全数据后才挂载，完整字库较大 | 先测关键路径，按需求拆首屏/延后非关键资源 |
| 桌面开始只是手机窄条 | 把移动优先误当桌面不用设计 | 一开始确认两端要求，宽屏重新分配空间 |
| 国内访问后来才讨论 | 把当前网络上线成功误当全球可访问 | 在托管与地图选型前确认受众网络，单独实测 |
| 弹层第二次才关闭 | 关闭依赖包含iframe的浏览历史事件 | 立即释放界面并测试历史策略，不靠第二次点击 |
| 透明车背后出现地图 | 继承了精灵图背景 | 对单图检查background-image及截图 |

## 本案例偏好，不是全球约束

本次选择手写文楷、AI书法、纸感票、杉叶、三把不同伞和夸张第四位角色；用户多次修改显隐时机、胶囊大小与标题。这些是当前产品审美。

跨国可复用的是：真实资料、可改文字、素材与状态契约、实际帧验收、模块调度、双端设计与发布证据。不要把日本站名、票种、时区、人物笑点和秒数拷到别的国家。

## 截止本次的证据边界

- 实际网页数据：六天46事件；这是案例数量，不是Skill约束。
- 已有8项核心测试证明所覆盖逻辑，不代表全球DST、所有设备或全部无障碍已测。
- 正式部署和多次资源哈希、浏览器交互有回执；部分步骤由模块/部署任务完成，部分由主任务复核。
- 桌面1024/1440及手机375/390视口检查有记录；没有全量真实手机微信验收。
- 国内无代理稳定访问没有被证明；不要回写成“需VPN已实测”或“国内可用已保证”。
- 清单小背包仍是未采用探索，未因“所有分支都推”而进入正式站。
- 本次Skill的新评分表与未来场景测试是现在的归纳，不冒称开发当天已全程按它打过分。
