# 功能覆盖与租赁细节

从旧参考中的原子功能清单提炼；保留检查粒度，不继承单页、配色、固定页签数量或特定国家规则。

## 项目覆盖表

启动或大改时在现有工作记录中维护一张表即可。沿用已有ID，没有才使用下列编号。每行记录：适用依据、页面/组件、状态、证据、未测项。状态为待做/已实现/已验证/不适用；“已采用”与“已发布”仍由调度表单独跟踪。

| ID | 要检查的能力 | 可观察结果 |
| --- | --- | --- |
| ID01 | 标题与分享元信息 | 初始标题、运行时标题、分享标题一致 |
| NAV01 | 页面入口 | 每个入口到达约定页面，当前状态正确 |
| NAV02 | 深链接与返回 | 刷新、前进后退、重复点击保持约定行为 |
| HOME01 | 开场与降级（如有） | 正常播放、跳过、减少动态效果都能进入内容 |
| FL01 | 完整航段 | 起终点/中转、航班号、航站楼和日期对应 |
| FL02 | 时间与截止 | 按绝对时刻计算，跨区/跨日/过期正确 |
| FL03 | 多卡状态 | 横滑、按钮、页码与重新显示一致 |
| MAP01 | 路线总览 | 空间关系与行程顺序可理解，意象不冒充导航 |
| MAP02 | 地点目标 | 目录、原名、地址及地图目标对应 |
| MAP03 | 地图退出与失败 | 单击关闭回原位；失败仍可复制和离开 |
| DAY01 | 全部日期与活动 | 无遗漏、重复或错配，精确时刻与时段分清 |
| DAY02 | 展开与阅读上下文 | 展开/收起/地图返回后状态和焦点合理 |
| STAY01 | 住宿与餐饮 | 入住日期正确，候选与已订不同，实际入口可查 |
| TKT01 | 票务与预约 | 个人勾选可逆，共享票项联动，不冒充出票证据 |
| COST01 | 费用 | 名称、币种、参考/实付/待付及包含范围清楚 |
| MOVE01 | 地面交通 | 当前适用方式、购票和换乘说明可执行 |
| PREP01 | 输入与计数 | 空白/重复/输入法/增勾删撤正确 |
| PREP02 | 保存边界 | 刷新保留，存储失败说明，不虚称跨人同步 |
| DATA01 | 单处数据更新 | 相关页面和提醒联动，无第二套硬编码事实 |
| SRC01 | 来源与公开范围 | 事实可追溯，发布文件不带不应公开的信息 |
| UI01 | 手机与桌面 | 目标尺寸可读可操作，无遮挡和错误裁切 |
| REL01 | 正式更新 | 正确提交到原网址，变化资源及功能回读 |
| REC01 | 恢复（按风险） | 旧产物可恢复且用户状态兼容；未演练明确未测 |

这是检查索引，不是新增功能的授权。简单无航班旅行可以将FL类记不适用；需要多人同步时再补该项目的身份、权限、冲突及双会话验收行。模块实现细节仍以[功能契约](module-features.md)为主。

## 租车/租赁：仅在旅行适用时展开

以实际订单和当地官方/供应商说明为准。车辆、露营车、摩托车等可复用关系；不把某一交通工具的属性强套给另一种租赁。

| ID | 数据或能力 | 验收结果 |
| --- | --- | --- |
| RENT01 | 供应商与门店 | 品牌、实际取还门店清楚，不把平台当门店 |
| RENT02 | 车型或产品 | 保留“或同级”等替代条件，不承诺示例车型 |
| RENT03 | 级别/容量 | 座位、行李等与订单一致，未知不猜 |
| RENT04 | 必要配置 | 变速/驱动/电池或其他相关属性只列有依据者 |
| RENT05 | 里程与使用范围 | 无限/限额、超额费用、跨境限制不被遗漏 |
| RENT06 | 取用时刻 | 日期、当地时区、门店营业/延迟要求对应 |
| RENT07 | 取用地点 | 地址、门店原名、机场接驳或入口可找到 |
| RENT08 | 归还时刻 | 最晚日期与时区明确，不混为一般活动时间 |
| RENT09 | 归还地点 | 异地归还用实际门店，不沿用取车地址 |
| RENT10 | 租期计价 | 订单计价天数与自然日区别保留，不自行改价格 |
| RENT11 | 支付时机 | 已付、到店付、预授权分别表达 |
| RENT12 | 金额与币种 | 基价、已含、待付和参考价不混写 |
| RENT13 | 押金与支付工具 | 金额/卡片与持卡要求有依据，敏感卡资料不公开 |
| RENT14 | 额外费用 | 异地费、额外驾驶人、儿童座椅等按订单取用 |
| RENT15 | 燃油/充电政策 | 取还要求与补充费用明确，不能默认满油满还 |
| RENT16 | 退改与迟到 | 截止时区、费用、失约规则按当前订单核验 |
| RENT17 | 保障原名 | 保障正式名称和中文含义并存，不随意合并不同保障 |
| RENT18 | 免赔与排除 | 自负额、除外责任、附加保障取自条款，不推断“全险” |
| RENT19 | 资格文件 | 驾照、翻译/许可、年龄、驾驶人要求按当地规则核验 |
| RENT20 | 取用检查 | 外观损伤、照片、设备、油电量/里程等实际检查可记录 |
| RENT21 | 归还检查 | 地点、时间、照片、钥匙交还、油电量与凭据可执行 |
| RENT22 | 故障或事故联络 | 供应商公开联络与流程可查，不编造当地号码 |
| RENT23 | 当地使用规则 | 行驶方向、收费/停车等与目的地一致，不搬旧国家经验 |
| RENT24 | 独立归还提醒 | 用户需要时同时显示绝对截止、地点、时区和独立倒计时 |
| RENT25 | 信息组织与状态 | 概要与检查/保障/规则可分组，切换不丢记录，不强制三页签 |

归还倒计时不能由一个静态日期冒充。修改归还门店或时刻后，应同步概要、提醒、地图和相关日程。预约、购买或变更订单仍按当次授权执行。
