# HotelAtmosphere 合约

## 目的与边界

`HotelAtmosphere` 是每晚住宿段上方的原创 SVG 空间抽象，固定用于约 `280 × 150px` 的手机区域。它只承载气氛和触摸反馈；酒店名称、日期、地址、入口、已订状态、地图和任何入住事实由父组件提供。它不使用酒店照片、logo、客房图、实时定位、浏览器存储或网络请求。

```jsx
import HotelAtmosphere from './HotelAtmosphere.jsx';

<HotelAtmosphere kind="okura" />
```

## 公开接口

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `kind` | `'manpa' | 'fujiya' | 'taoya' | 'imperial' | 'okura'` | `'manpa'` | 对应真实住宿 `hotelId` 的空间气氛；无效值回退为 `manpa`。 |

| hotelId | kind | 原创画面语汇 | 触碰反馈 |
| --- | --- | --- | --- |
| `manpa` | `manpa` | 岬端 270 度海平线、露台木面、暮光 | 海面细环从触点扩散，露台光轻亮 |
| `fujiya` | `fujiya` | 河石、清水、水脉、涌泉细环 | 河道水纹从触点扩散，泉眼短暂变亮 |
| `taoya` | `taoya` | 海湾夕照、暖木格栅、水面反射 | 水面细光扩散，木格接住一束短光 |
| `imperial` | `imperial` | 透光玻璃小砖、阶梯暗面、细金光 | 玻璃亮度从触点附近向外传开 |
| `okura` | `okura` | 桧木色几何留白、多面灯、近黑漆与少许朱红 | 灯轮廓轻摆／变亮，大麻叶格显出静态触点层次 |

## 行为合约

- **静止完成态**：五种场景即使没有播放动画，也已具备完整材质、层级和可辨识轮廓；不会出现加载占位。
- **首次入视**：IntersectionObserver 第一次进入约 18% 可视区时，以 CSS 的透明度、缩放和清晰度柔和建立一次。此后不重复“进场”。
- **离屏暂停**：离开可视区会给所有 CSS 动画加 `animation-play-state: paused`；返回只继续低幅呼吸／水纹，不重演首次建立。
- **触碰**：`pointerdown` 转换为 SVG 坐标，产生 3 圈短暂扩散，1.0–1.5 秒自动收束；连续点击重置反馈。组件不阻止页面滚动，也不要求 hover。
- **减少动态效果**：检测 `prefers-reduced-motion: reduce`。不自动播放或入场过渡，但保留触碰后的静态亮点／同心环，以便仍得到操作反馈。
- **无事实文案**：SVG 只含无障碍标签，视觉内不写酒店事实；父级需要另外显示正确的住宿和入口信息。

## 溯源与禁止推断

- `imperial` 仅把帝国饭店公开描述中的 Reimei 玻璃砖与细金光转成原创抽象，未复刻其艺术品构图，也不表示预订房型或实际大厅动线。
- `okura` 仅把 5F 大厅公开描述中的桧木大麻叶格、多面灯、漆黑／朱红桌面关系转成原创抽象；父级必须保留“住宿走正面入口 5F”的事实，图形本身不代表入口、楼层或住客权益。
- 其余三种场景同样是对目的地／住宿环境的原创氛围表达，不是房间照片、现场实景、导航或天气状态。

## 父级接入检查

1. 用真实 `hotelId` 传入对应 `kind`；保留现有地图、票券、清单和酒店事实的数据来源。
2. 在 375px 和 390px 下确认卡片不挤压主要操作；其最大视觉宽度为 280px，高度为 150px。
3. 分别检查默认、首入视、离屏再入、连续点按、`prefers-reduced-motion` 五种状态。此合约未替代浏览器／真机验收。
