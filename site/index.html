Turn your travel materials into a personal, shareable travel website.

These are live roadbooks built with travel.skill: three fictional trips made from the dependency-free template, and the real trip the project grew out of. Open one on your phone.

Make yours

git clone https://github.com/clarkchenkai/travel.skill && cd travel.skill
npm run new -- europe-rail && npm run dev     # then edit trip/travel-data.json

Or open the repo in Claude Code / Codex, drop your bookings and notes into input/, and say: "Build my travel roadbook with the travel skill." Nothing to install beyond Node 20, no account, no database.
