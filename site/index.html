TRAVEL NOTES / 001
01 / 一份真实作品KUMANO · TOKYO

熊野古道，
和沿途的每一件小事。

四个人，六天。
从杉林、石阶走向东京；
也把航班、换乘和每天的安排放在手边。

路线从全程总览，找到具体地点。

日程按天展开，查看安排与住宿。

交通航班、时区与沿途换乘。

清单逐项勾选，记录留在当前浏览器。

短片展示开场、路线、日程与交通；清单可在完整路书中使用。

02 / 从你的资料开始MATERIALS → ROADBOOK

不必先整理得井井有条。

i.

带来资料

订单、链接、零散笔记，
还有已经决定的事。

ii.

补齐关键缺口

日期、地点、换乘与待办，
不确定的地方先标清。

iii.

生成自己的路书

在手机上查看与修改，
确认公开内容后再分享。

通过仓库里的 Agent Skill 与本地命令完成；此页不接收订单或私人资料。

03 / 另外三种出发方式FICTIONAL ITINERARIES

从一个接近你的旅程开始。

以下均为虚构示例，展示轻量模板的不同起点；熊野古道是单独定制的作品。

04 / 轮到你的旅程YOUR NEXT JOURNEY

把下一站，交给一张空白页。

用 Claude Code 或 Codex 打开仓库，把资料放进 input/，然后说：

用 travel skill，把这些资料做成我的旅行路书。
先标出缺失信息，再生成可以预览的网站。
本地启动命令
git clone https://github.com/clarkchenkai/travel.skill
cd travel.skill
npm run new -- europe-rail
npm run dev

轻量模板需要 Node.js 20+。公开发布前检查内容与访问范围。
